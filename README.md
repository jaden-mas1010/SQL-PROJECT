# SQL-PROJECT# Employee Device & Login Analysis 
## Overview
This project analyzes employee device information and login activity using SQL. It demonstrates both basic and advanced SQL skills:
- Selecting and filtering data
- Aggregation and grouping
- Ordering and limiting results
- Joining tables
- Window functions
- Anomaly detection

## Folder Structure
- `machines_basic.sql`: Basic selects from `machines` table.
- `machines_advanced.sql`: Aggregations, filtering, and joins on `machines`.
- `login_analysis.sql`: Advanced login activity queries, anomaly detection, ordering, and window functions.
- `sample_data/`: CSV files containing sample data.

## Skills Demonstrated
- SQL SELECT, WHERE, ORDER BY
- Aggregation (`COUNT`, `SUM`, `GROUP BY`, `HAVING`)
- Joins (`INNER JOIN`, `LEFT JOIN`)
- Window functions (`OVER(PARTITION BY...)`)
- Anomaly detection
- Query optimization and readability
This is designed as a **portfolio project** to demonstrate SQL and data analysis skills to recruiters.
